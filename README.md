# PTU ECE Virtual Lab 

Welcome to the **PTU ECE Virtual Lab**! This is your new digital playground for exploring communication signals.

We replaced the heavy, complicated software. This is a completely browser-based simulator designed to make learning digital modulation fun and engaging. No gimmicks, just interactive learning.

## What's the Tea? (Features)
Jump right into the main digital modulation schemes. We've got:
* **ASK (Amplitude Shift Keying) ➔** `ask.html` - *Riding those amplitude waves.*
* **FSK (Frequency Shift Keying) ➔** `fsk.html` - *Changing the frequency like a DJ.*
* **BPSK (Binary Phase Shift Keying) ➔** `bpsk.html` - *Flipping phases and taking names.*

## The Vibe Check (Tech Stack)
Keeping it fast and completely free of dependencies:
* **HTML5, CSS, & JS:** 100% pure web goodness. No bloated frameworks here, just clean code.
