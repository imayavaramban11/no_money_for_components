Aim

To study Frequency Shift Keying (FSK) modulation and demodulation techniques.

Objectives:

  • Understand FSK modulation principles and how binary data is represented using different frequencies
  • Generate FSK signals from binary data and observe the frequency transitions
  • Implement FSK demodulation using correlation-based detection
  • Analyze the effect of noise on FSK signal transmission
  • Calculate important parameters like modulation index, bandwidth, and bit error rate

Theory

Introduction to FSK

Frequency Shift Keying (FSK) is a digital modulation technique where the frequency of the carrier signal varies according to the digital signal being transmitted. In binary FSK, two distinct frequencies represent binary 0 and binary 1.

FSK Mathematical Representation

For binary FSK, the modulated signal can be represented as:

s(t) = A·cos(2πf₁t) for binary '1'

s(t) = A·cos(2πf₂t) for binary '0'

where A is the amplitude, f₁ is the mark frequency (binary 1), and f₂ is the space frequency (binary 0).

Key Parameters

  • Frequency Deviation (Δf): |f₁ - f₂| - the difference between the two carrier frequencies
  • Modulation Index (h): Δf / bit rate - determines spectral efficiency
  • Bandwidth: Approximately 2(Δf + bit rate) using Carson's rule

FSK Demodulation

FSK signals can be demodulated using coherent or non-coherent detection methods. This simulation uses correlation-based coherent detection, where the received signal is correlated with reference carriers at f₁ and f₂ frequencies to determine which bit was transmitted.

Applications

  • Caller ID systems
  • Radio teletype (RTTY)
  • Low-speed modems
  • RFID systems
  • Wireless sensor networks

Procedure

Step-by-Step Instructions:

  1. Enter Binary Sequence: Type your desired binary sequence (e.g., 10110100) in the Binary Input field. Only 0s and 1s are allowed.
  2. Set Carrier Frequencies:
    • Set Mark frequency f₁ (for binary 1) - typically higher frequency
    • Set Space frequency f₂ (for binary 0) - typically lower frequency
  3. Configure Parameters:
    • Set bit rate (bps) - determines symbol duration
    • Set amplitude (V) - signal amplitude
    • Set sample rate (Hz) - should be at least 2× highest frequency
    • Set SNR (dB) - signal-to-noise ratio for channel simulation
  4. Generate Signal: Click "Generate Signal" button to create the FSK modulated signal.
  5. Run Simulation: Click "Run" to start the simulation and see all waveforms.
  6. Adjust Oscilloscope: Use oscilloscope controls to adjust time base and voltage scales for better visualization.
  7. Analyze Results: Review the Result Summary section for calculated parameters and performance metrics.
  8. Experiment: Try different bit sequences, frequencies, and SNR values to observe their effects.
  9. Reset: Click "Reset" to clear all plots and start over.
